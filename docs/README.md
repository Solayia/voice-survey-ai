# docs/

## Rôle

Ce dossier est la **source de vérité** de VoiceSurvey AI. Le projet est piloté
par la documentation : chaque décision importante y est consignée *avant* d'être
implémentée.

## Contenu

- `00_INDEX.md` — l'**index** de navigation de toute la documentation.
- `01` … `25` — les documents du projet (vision, architecture, sécurité, etc.).
- `adr/` — les **Architecture Decision Records** (décisions techniques).

## Conventions

- Tous les documents sont rédigés en **français**.
- Fichiers numérotés et préfixés pour un ordre de lecture clair.
- Chaque décision technique significative donne lieu à un ADR (voir `adr/`).
- Aucune fonctionnalité n'est développée tant que sa documentation n'est pas
  rédigée, relue et validée.

👉 Commencez par [`00_INDEX.md`](00_INDEX.md).

> 🟡 **Phase d'amorçage.** Les documents `01`–`25` sont des **placeholders** :
> leur structure existe, mais leur contenu n'est volontairement pas encore
> rédigé.
